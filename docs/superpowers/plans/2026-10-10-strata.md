# STRATA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build STRATA: an ensemble music analyzer that writes one canonical `analysis.json`, with exporters, a live OSC clock, a web UI with a color-coded timeline and visualizer, and a Claude skill.

**Architecture:**
- A Python package `strata` runs per-dimension backends. Each backend is cached in the library and recorded in provenance.
- Results are merged by voting ensembles, and derived layers (builds/drops/cues) are added on top.
- Everything downstream (exporters, server, UI, skill) reads only `analysis.json` (schema 1, spec §6).

**Tech Stack:**
- Python 3.12, torch 2.11 cu128, demucs, beat_this, allin1 (vendored PR #39), madmom (git, NC), S-KEY, BTC (vendored), basic-pitch (ONNX), pyloudnorm, librosa, transformers CLAP, FastAPI, python-osc, mido
- Vite + TypeScript, Canvas2D/WebGL2
- pytest, Playwright

**Spec:** `docs/superpowers/specs/2026-10-10-strata-design.md`

## Global Constraints

- Code license MIT. NC backends are opt-in (`[nc]` extra) and are excluded when `profile == "commercial-safe"`.
- Python `>=3.12`. Torch comes from the cu128 index. basic-pitch is installed `--no-deps` with onnxruntime.
- `analysis.json` follows spec §6 exactly:
  - times in seconds, 3 dp
  - lists time-sorted
  - curves normalized 0..1, 4 dp
  - `strata.schema == 1`
- A failing backend never aborts a run. It is recorded as `ok:false` with an `error` string.
- Library root is `$STRATA_HOME`, default `~/.strata`. Track id is `sha256(file bytes)[:16]`.
- Section and stem colors are copied verbatim from spec §7.
- No silent installs. NC weights are never copied into the repo.

## Review Focus

1. **Mono, short (<10 s), or silent audio.** Expect a valid JSON with empty or low-confidence layers, not a crash. Test: `tests/test_pipeline.py::test_silent_and_short_audio`.
2. **Tracks with no beat (ambient/rubato).** Expect empty or low-confidence beats, `tempo.stable=false`, sections still present. Test: `tests/test_ensemble_beats.py::test_no_reference_beats`.
3. **Non-44.1k sample rates and mp3/flac/aif input.** All of them should load the same way. Test: `tests/test_audio.py::test_formats_and_rates`.
4. **Re-running the same file.** Expect cache hits and identical output, with no re-separation. Test: `tests/test_pipeline.py::test_cache_reuse`.
5. **Unicode paths and spaces in filenames,** carried through to exporters (XML escaping, JSX string escaping). Test: `tests/test_exporters.py::test_unicode_title_escaping`.

- [ ] Step 1: Tests (synthetic):

- [ ] Step 2: FAIL. Step 3: implement:
  - **Reference:** the backend with the max weight among non-empty results.
  - **Matching:** within ±70 ms; confidence = Σ weights of agreeing others / Σ weights of the other non-empty backends.
  - **Insertion:** gaps over 1.5 × median IBI.
  - **Downbeat Viterbi:** M states, emission = weighted downbeat vote for state 0 and its complement otherwise; transition s→(s+1)%M has log-prob 0, any other state log(0.01).
  - **Tempo map:** 60/IBI with an 8-beat median filter; `stable` per the spec.
  - **Alternatives:** the median IBI ratio of each other backend against the reference, in {0.5, 2, 2/3, 1.5} ± 5%.
- [ ] Step 4: PASS. Step 5: commit `feat: beat backends + ensemble`.

### Task 5: Sections (SSM backend + ensemble)

**Files:**
- Create: `strata/backends/sections_ssm.py`, `strata/ensemble/segments.py`
- Test: `tests/test_ensemble_segments.py`

**Interfaces:**
- **Produces:**
  - The SSM backend runs after beats (`requires=("beat_this",)`) and returns `{"boundaries": [t], "labels": ["A", "B", ...]}`. Features: beat-synchronous CQT chroma + 13 MFCC, then a recurrence matrix (librosa `recurrence_matrix(mode="affinity")`), then a checkerboard novelty (kernel 16 beats), then peak pick (min distance 8 beats). Labels come from agglomerative clustering of mean segment features with a 0.5 distance threshold.
  - `merge_sections(cands: dict[str, dict], weights: dict, beats: list, duration: float) -> list[section]`

  - snapping to a downbeat within 1 beat
  - labels taken from the allin1 overlap
  - without allin1, A/B labels are used

### Task 7: Drums, features/curves, dynamics, notes, vocals, tags, lyrics

**Files:**
- Create: `strata/backends/drums_bands.py`, `features.py`, `notes_basicpitch.py`, `vocals_activity.py`, `tags_clap.py` (optional), `lyrics_whisper.py` (optional)
- Test: `tests/test_drums_features.py`

**Interfaces:**
- **drums_bands** (requires stems; falls back to the full mix):
  - Bandpass the drum stem into kick (30–150 Hz), snare (180–2500 Hz plus 4–8 kHz noise), hat (>7 kHz).
  - Each band gets an onset envelope (spectral flux, hop 256), then `librosa.util.peak_pick` with an adaptive threshold (median plus k·MAD) and a 50 ms refractory.
  - At each onset, the band whose energy ratio is dominant wins.
  - Returns `{"kick": [{"time", "strength"}], "snare": [...], "hat": [...], "onsets": [...]}`.
- **features:**
  - `{"fps", "names", "data": {name: list}}` for every curve in spec §6, plus `{"lufs", "lra", "peak_db", "silences"}`
  - curves are resampled to `ceil(duration*fps)` frames and min-max normalized with a 1st-99th percentile clip
- **notes_basicpitch:** `predict(stem_path, model_or_model_path=ICASSP_2022_MODEL_PATH onnx)`. Returns `{"bass": [...], "vocals": [...], "other": [...]}` in note dicts.
- **vocals_activity:** frames where vocal-stem RMS is above −40 dBFS and above 0.15 of the vocal max, merged with a 0.3 s gap. Returns `{"activity": [...]}`.
- **tags_clap:**
  - `laion/larger_clap_music` via transformers, with curated label lists in `strata/backends/tag_labels.py`
  - global = 10 s windows averaged; per section = windows inside that section
  - returns `{"genre", "mood", "instruments", "sections": [[tags]]}`
- **lyrics_whisper:** faster-whisper `large-v3-turbo` with word_timestamps, run on the vocal stem only when activity is above 5% of the track.
- [ ] Step 1: Tests (synthetic):
  - a track with 60 Hz sine kicks every 0.5 s plus 10 kHz noise hats on the off-beats → kicks within 15 ms of truth (F > 0.95), hats likewise
  - curve lengths equal `ceil(dur*fps)`, values in 0..1
  - a silence in the middle (2 s of zeros) is reported in `silences`
- [ ] Steps 2-5: FAIL → implement → PASS → commit `feat: drums, curves, dynamics, notes, vocals, tags`.
